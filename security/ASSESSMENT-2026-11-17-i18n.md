# 1.2.0 語言切換驗證

日期：2026-11-17。新增功能為繁體中文與英文的手動切換。

## 資料與權限

沿用 `storage` 權限，於 `chrome.storage.local` 的既有 `enabled` 之外，新增 `language` 偏好，僅接受 `zh-TW` 或 `en`，其他值回復繁體中文。未新增網路請求、帳號讀取、背景服務、額外網站範圍或遠端資源。

所有翻譯隨套件封裝，使用 `textContent` 設定文字。語言變更只更新設定視窗與重播按鈕，不修改 YouTube 文件本身的語言、開關設定、影片進度或暫停狀態。

## 驗證

- 39 項回歸測試通過，包含語言保存、英文錯誤訊息、儲存失敗回復、未知語言回退，以及延遲讀取設定與即時語言事件之競態。
- JavaScript 語法檢查及既有 9 份證據檔案的雜湊驗證通過。
- 獨立 Chromium 148.0.7778.96／Playwright 1.62.1 原生載入當前工作目錄：10 項受控瀏覽器檢查／量測通過；另重現既有 FUNC-01 條件性功能問題，不計為通過。
- 新增 BR-11 確認設定視窗中英文切換、重新載入後保存、兩個 YouTube 分頁上的重播按鈕即時更新，以及選擇語言不恢復播放或開啟循環。
- 已目視檢查兩種語言的深色設定視窗截圖，文字與控制項未截斷。

瀏覽器測試使用受控 HTTPS 回應與自行產生的影片，不是真實 YouTube。此次未重跑真實網站測試；上一次 1.1.0 的真實 YouTube 測試在等待影片就緒時受阻。現有隱藏影片事件問題與效能限制見 [1.1.0 驗證紀錄](ASSESSMENT-2026-11-17.md)。

瀏覽器測試以未提交的 1.2.0 工作目錄執行，結果另記錄執行時檔案雜湊，保存在忽略提交的 `dist/security/language-1.2.0-verified/`。重跑方式見 [SECURITY.md](../SECURITY.md)。
